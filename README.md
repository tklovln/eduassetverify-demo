# EduAssetVerify: demo page

Static project page of the paper (`index.html`): a game-card scenario, a production-line
simulation, every module on one test asset, a rule playground, a spot-the-error game, the
counterfactual pairs, the result dashboard, and all 900 test assets with every verdict of every
pass, their evidence, measurements and reports.

All files are generated from the experiment records; do not edit them by hand. `media/` holds the
images (lossless, native 512 x 512) and per-asset details, one script per template; `fonts/` the
licenses of the two embedded web fonts (SIL Open Font License 1.1).
